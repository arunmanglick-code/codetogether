# Decision 001: Create a Decision Log

**Date:** 2026-07-02  
**Status:** Accepted

## Context
Track all architectural, technology, and design decisions made during the project session in a single place for future reference.

## Decision
Create a `decisions/` folder using lightweight ADR (Architecture Decision Record) format. Each file is numbered sequentially (`NNN-short-title.md`) and follows a consistent template: Context, Decision, Consequences.

## Consequences
- All future decisions will be logged here as new files.
- Provides a clear audit trail for why choices were made.

   - Later phases should introduce backend services and database integration.

3. **Clarifications**
   - Ask me clarifying questions where requirements are ambiguous (e.g., preferred frontend framework, hosting environment, CI/CD needs).

4. **Task Tracking**
   - Create a file `portfolio_tasks.md` that lists all tasks per phase.
   - Tasks should be actionable, testable, and traceable.

5. **Decision Logging**
   - Create a folder `decisions/` where each major decision is logged in Markdown files.
   - Each decision entry should include:
     - Decision taken
     - Reasoning
     - Timestamp
     - Phase context

### Output Requirements
- Provide a **structured, multi‑phase plan** (Phase 1: static site, Phase 2: backend, Phase 3: database, etc.).
- Highlight dependencies and risks for each phase.

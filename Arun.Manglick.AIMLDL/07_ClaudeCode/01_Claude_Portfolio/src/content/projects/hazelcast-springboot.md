A Spring Boot application demonstrating distributed caching with Hazelcast, including both embedded and Kubernetes-native deployment modes. The project implements REST CRUD operations backed by Hazelcast's in-memory data grid for high-performance data access. It covers cache configuration, cluster discovery in Kubernetes environments, and integration patterns for production-grade caching solutions.

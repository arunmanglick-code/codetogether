Agent-based systems built with LangGraph that model complex workflows as directed graphs with cycles, conditional edges, and state management. The project demonstrates how to compose multi-step reasoning chains where agents can loop back, branch conditionally, and checkpoint their progress. This provides a more controllable and debuggable alternative to fully autonomous agent loops.

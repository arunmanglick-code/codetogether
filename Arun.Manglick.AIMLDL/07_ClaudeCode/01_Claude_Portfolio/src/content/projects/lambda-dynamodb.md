A serverless application that implements full CRUD operations using AWS Lambda functions backed by DynamoDB. The project demonstrates API Gateway integration for RESTful endpoints, DynamoDB DocumentClient usage for efficient data access, and single-table design patterns for NoSQL data modeling. Includes proper error handling, input validation, and IAM role configuration.

A complete monitoring and observability stack deployed with Docker Compose, combining Grafana for visualization, Telegraf for metric collection, and InfluxDB for time-series data storage. The project includes pre-configured Grafana dashboards for system health monitoring, Telegraf input plugins for collecting metrics from various sources, and InfluxDB retention policies for efficient long-term storage.

A set of Node.js accelerator projects that provide production-ready patterns for integrating with AWS services. Built with Express and the AWS SDK v3, these microservices demonstrate best practices for interacting with S3, DynamoDB, SQS, and other AWS services. The projects include AppRunner deployment configurations for quick, fully managed container hosting on AWS.

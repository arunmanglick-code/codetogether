An exploration of the Graphiti framework for building dynamic knowledge graphs that evolve with new information. The project leverages Neo4j as the graph database backend and exposes data through GraphQL endpoints, enabling real-time ingestion of facts and relationships with full temporal tracking. This approach supports agentic AI systems that need persistent, queryable memory beyond simple vector stores.

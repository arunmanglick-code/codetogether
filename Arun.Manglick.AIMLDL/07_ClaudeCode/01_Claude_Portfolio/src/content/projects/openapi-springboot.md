A Spring Boot application that demonstrates integrating OpenAPI and Swagger for automatic REST API documentation generation. The project showcases how to annotate controllers and models to produce interactive API specifications that serve as both documentation and testing interfaces. It follows best practices for API-first development with machine-readable specifications.

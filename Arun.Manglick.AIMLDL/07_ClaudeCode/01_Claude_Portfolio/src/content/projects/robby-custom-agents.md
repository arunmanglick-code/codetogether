A Java-based framework for building and deploying custom AI agents using the Robby agent platform. The project follows standard Maven conventions and provides a structured approach to defining agent behaviors, capabilities, and interaction patterns. It serves as a foundation for creating specialized AI agents that can be extended for various use cases.

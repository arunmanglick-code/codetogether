End-to-end CI/CD pipelines that build Docker containers, push to ECR, and deploy to ECS Fargate using GitHub Actions. The project demonstrates multi-stage Docker builds for optimized container images, GitHub Actions workflow authoring with reusable steps, and ECS Fargate task definitions with service auto-scaling. Provides a production-ready template for containerized application deployment on AWS.

Automated API test suites built with REST Assured and JUnit for validating Java backend services. The project uses REST Assured's fluent BDD-style syntax for readable test specifications, covers CRUD endpoint validation with request and response assertions, and integrates with JUnit for structured test lifecycle management and reporting.

A library of reusable Terraform modules for provisioning and managing AWS infrastructure. The modules cover core services including VPC networking, EC2 compute instances, IAM policies, and security groups, all written in HCL with proper variable parameterization. The project follows Terraform best practices for state management, module composition, and multi-environment deployments.

A serverless email notification service built with AWS Lambda and Simple Email Service (SES). The project demonstrates how to send templated transactional emails triggered by application events, with proper SES configuration for sender verification, bounce handling, and delivery tracking. Designed as a reusable microservice for adding email capabilities to any serverless application.

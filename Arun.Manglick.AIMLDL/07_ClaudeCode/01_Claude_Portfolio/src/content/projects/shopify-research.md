A research project exploring Shopify platform integration with AWS AppRunner for managed container deployments. The Node.js and Express application investigates patterns for connecting Shopify storefronts with AWS cloud infrastructure. It documents findings on AppRunner's auto-scaling, deployment pipelines, and integration points with the Shopify API ecosystem.

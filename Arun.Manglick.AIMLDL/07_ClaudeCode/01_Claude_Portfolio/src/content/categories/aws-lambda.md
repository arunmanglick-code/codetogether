Serverless computing projects using AWS Lambda, demonstrating event-driven function design, API Gateway integrations, and connections to services like DynamoDB, SES for email, and Kinesis for stream processing. Covers patterns such as fan-out architectures, scheduled tasks, and cost-efficient microservice decomposition. These projects highlight the power of running backend logic without managing servers.

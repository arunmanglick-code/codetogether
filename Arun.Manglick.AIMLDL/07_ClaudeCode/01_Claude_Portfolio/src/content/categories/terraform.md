Infrastructure as code projects using Terraform to provision and manage AWS resources declaratively. Covers VPC networking, EC2 instances, RDS databases, IAM policies, and multi-environment configurations with workspaces and modules. These projects demonstrate repeatable, version-controlled infrastructure deployments that follow cloud engineering best practices.
